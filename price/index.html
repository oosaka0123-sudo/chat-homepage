料金

制作後は、自分で更新。更新料0円。
ホームページ制作後は、ChatGPTとGitHubを使って、お客様自身で文章や写真などを変更できます。必要な方だけ月額サポートをご利用いただけます。

料金の目安

ホームページ初期制作

150,000円〜

デザイン・ページ制作・スマホ対応・基本的なSEO設定・公開作業を含みます。ページ数や機能により金額は変わります。

AI更新環境・GitHub初期設定

初期制作費に含む

お客様自身がChatGPTからホームページを変更できるよう、GitHubを使った更新環境を初期設定します。

お客様自身での更新

0円

文章変更、写真差し替え、営業時間や料金の修正など、お客様自身で行う更新について当社への更新料はかかりません。

月額サポート

3,000円〜10,000円／月

操作に困ったときの相談や、当社による軽微な修正などを希望される方向けの任意サポートです。

大幅なデザイン変更・機能追加

別途お見積もり

新しい機能の追加、全面的なデザイン変更、大規模なページ追加などは内容を確認して事前にお見積もりします。

別途必要になることがある費用

GitHub

0円〜

無料プランで利用できる範囲があります。契約内容や利用方法によって費用が発生する場合があります。

ChatGPT

ご利用プランによる

ChatGPTの利用料金はOpenAIとのご契約となり、当社の制作料金には含まれません。

ドメイン・サーバー

実費

独自ドメインやレンタルサーバーが必要な場合は、各サービス提供会社への利用料金が別途必要です。

公開後の運用について

ホームページとGitHubの所有権は、原則としてお客様側で管理していただく設計です。当社にはサポートに必要な編集権限を付与していただくことで、トラブル時やご依頼時に修正をお手伝いできます。

普段の更新はお客様自身で行えるため、更新のたびに当社へ依頼する必要はありません。サポートが不要な場合は、月額サポートを契約せずに運用することもできます。

料金に関するよくある質問

自分で更新すると、そのたびに料金がかかりますか？

いいえ。当社への更新料は0円です。ChatGPTやGitHubなど外部サービスで有料プランをご利用の場合は、それぞれのサービス利用料が別途必要です。

月額サポートは必須ですか？

必須ではありません。ご自身で運用できる場合は、月額サポートなしで利用できます。

制作費は必ず150,000円ですか？

150,000円からが目安です。ページ数、デザイン、機能、掲載内容などによって正式な制作費は変わります。制作前にお見積もりをご提示します。

大きな変更をお願いする場合はいくらですか？

内容によって作業量が大きく異なるため、事前確認のうえ別途お見積もりします。
