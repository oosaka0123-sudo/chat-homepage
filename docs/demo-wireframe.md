# ワイヤーフレーム — 制作デモ3サイト（Issue #3）

対象: `demos/salon/` `demos/cafe/` `demos/reform/` の3つの架空デモサイト（各1ページ構成）＋ メインLPへの「制作デモ」導線追加。
方針: 3サイトは業種・タイポ・レイアウト・ナビ・CTAの表現をそれぞれ明確に変える。ただしAGENTS.mdの制作方針（表示速度優先・HTML即表示・ローディング画面禁止・紫グラデ/カード乱発NG）は3サイト共通で守る。

## 共通要件（3デモ共通）

- 各デモは`架空の店舗・企業のデモ”であることを常に明示する。
  - ページ最上部に「DEMOバナー」（架空サイトである旨 + トップページへ戻るリンク）を設置。
  - フッターにも同旨の注記とリンクを再掲（バナーを見落としても必ず気づける二重導線）。
  - 戻り先は `../../`（相対）。
- 実在すると誤解される情報を出さない。
  - 地名は「架空市」固定（「架空」の語を含む地名にすることで、一目でダミーだと分かるようにする）。
  - 電話番号・予約フォームなど実際に機能する連絡手段は設置しない。「デモのため設置していません」を明記し、本物の相談窓口（chatホームページ本体の`#contact`）へ誘導する。
- 各ページはHTML単独で主要情報が読める。JSは未使用（3デモとも0JS。ナビはJSなしで機能するCSSのみ実装）。
- 画像は使用せず、SVG/CSSで装飾（ギャラリー相当のセクションも抽象的な模様＋キャプションで表現し、実在の写真や第三者ロゴを模したものにしない）。
- 見出し階層はH1を1つのみ、以降H2→H3。
- `id`はページ内で重複させない。ナビの`href="#..."`は同一ページ内に対応する`id`を必ず用意する。

## ページ共通のセクション骨格

1. DEMOバナー（ページ最上部、`header`より前）
2. Header / ロゴ + ナビ（サイトごとに構造・見た目を変える）
3. Hero（H1 + サブコピー + CTA）
4. コンセプト/事業紹介（H2）
5. メニュー/サービス一覧（H2）
6. こだわり・選ばれる理由（H2）
7. ギャラリー相当（H2、CSS/SVGの抽象ビジュアル+キャプション）
8. ご案内（H2、営業時間・架空所在地・デモ注記・本物の相談窓口へのCTA）
9. Footer（DEMO注記の再掲、戻りリンク、コピーライト）

以下、サイトごとの差分。

## 1. demos/salon/ — Hair Atelier 凪（美容サロン）

- コンセプト: 完全予約制の静かなプライベートヘアサロン。
- ナビ項目: コンセプト(`#concept`) / メニュー(`#menu`) / こだわり(`#features`) / ギャラリー(`#gallery`) / ご案内(`#info`)
- Hero: 「静けさの中で、髪と向き合う。」+ サブコピーに「※架空店舗のデモです」を明記。
- メニュー: カット/カラー/トリートメント/縮毛矯正を価格帯付きリストで（テーブルまたは`dl`、カード化しない）。
- こだわり: 完全予約制 / 担当制 / 個室空間の3項目。
- ギャラリー: 抽象的な幾何模様3〜4枚 + 短いキャプション（実在写真の代替として、サロンの雰囲気を言葉と模様で表現）。
- ご案内: 営業時間（架空）、所在地「架空市」、デモ注記、本物のご相談へのCTA。

## 2. demos/cafe/ — 喫茶ひなた（カフェ）

- コンセプト: 街角の小さな喫茶店。自家焙煎・手作りスイーツ。
- ナビ項目: ホーム(`#top`) / こだわり(`#concept`) / メニュー(`#menu`) / 店内のようす(`#gallery`) / ご案内(`#info`)
- Hero: 「一杯のコーヒーで、ひとやすみ。」+ 「※架空店舗のデモです」。
- メニュー: ブレンド/カフェラテ/自家製プリン/本日のケーキを価格付きで、チャルクボード風の一覧表示。
- こだわり: 自家焙煎 / 手作りスイーツ / 一人でも入りやすい雰囲気の3項目。
- ギャラリー: 暖色の有機的な模様（ブロブ形状）3〜4枚 + キャプション。
- ご案内: 営業時間、所在地「架空市」、デモ注記、CTA。

## 3. demos/reform/ — REBASE（住宅リフォーム）

- コンセプト: 住宅リフォーム専門の架空企業。信頼感・技術感を重視。
- ナビ項目: 事業内容(`#services`) / 選ばれる理由(`#features`) / 施工の流れ(`#process`) / 実績(`#gallery`) / 会社概要(`#info`)
- Hero: 「暮らしに合わせて、住まいを再設計する。」+ 「※架空企業のデモです」。
- 事業内容: キッチン改装 / 浴室・水回り / 外壁・屋根 / バリアフリー化の4項目（番号付き、図面風）。
- 選ばれる理由: 自社施工 / 明確な見積り / 保証・アフター対応の3項目。
- 施工の流れ: 相談→現地調査→提案・見積→施工→完工チェックの5ステップ（タイムライン）。
- 実績: Before/After相当の抽象的な二分割パネル（色面のみ、実在写真は使わない）+ キャプション。
- 会社概要: 所在地「架空市」、設立年（架空）、デモ注記、CTA。

## メインLP（index.html）への追加

- 新セクション `id="demos"`「制作デモ」を追加。
  - 配置: `#features`（できること）の直後、`#comparison`（比較表）の直前。
  - 内容: 3デモへのリンクリスト（3列グリッド、カード乱発を避けて既存の`.benefit`と同系統の罫線ベース表現に統一）。各項目に「DEMO・架空サイト」バッジ、タイトル、一言説明、リンクを設置。
  - リンク先: `demos/salon/` `demos/cafe/` `demos/reform/`（相対パス）。
- ナビに1項目追加: 「制作デモ」を`#features`と`#pricing`の間、`#demos`へのアンカーとして追加。既存8項目→9項目。モバイルはトグル式の縦積みリストのため項目数増加による過密は発生しない。デスクトップ幅で折れないよう、ナビの`flex-wrap`を保険的に許可する。
