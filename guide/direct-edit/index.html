DIRECT EDIT / GITHUB CONNECTION

ホームページを
直接編集したい方へ

このページは、ChatGPTに修正を頼むだけでホームページ本体まで反映したい方向けです。ホームページのデータはGitHub（ギットハブ）に保存されているため、ChatGPTとGitHubを最初に接続します。

しくみ： ChatGPTで依頼 → GitHubのホームページデータを変更 → 公開サイトへ反映

必要な設定を見る大切な注意点
最初の接続だけ以後はチャットで依頼対象サイトだけに権限限定

まず知っておくこと

共有チャットに入るだけでは編集できません

共有プロジェクトへの参加と、ホームページ本体の編集権限は別です。

共有プロジェクトに参加すると、ChatGPTとの会話や修正依頼はできます。ただし、それだけではホームページ本体を書き換えることはできません。

実際にホームページを変更するには、GitHubへの接続と編集権限が必要です。

GitHubを接続すると

お願いを、そのままホームページへ反映できます

接続と権限設定が終わると、普段の会話と同じように変更内容を伝えられます。

  • ボタンの削除・追加
  • 文章の変更
  • 写真の差し替え
  • 新しいページの追加
  • デザインの修正
  • 既存ページの更新

設定は最初だけ

最初に1回、GitHubを接続します

接続後は、普段どおりChatGPTに変更内容を伝えるだけで進められます。

1

ChatGPTにGitHubアプリを追加して接続

ChatGPTのサイドバー、または「設定 → Plugins」からGitHubを追加し、GitHubアカウントで接続します。権限を許可するときは、このホームページのリポジトリだけを選んでください。スマホでGitHubを確認する方は、GitHub公式アプリもインストールしておくと管理しやすくなります。

2

編集権限を確認

見るだけではなく、対象ホームページを変更できる権限が必要です。

3

いつもの言葉で依頼

専門用語を使わず、変更したい内容をそのまま伝えます。

接続後の依頼例

「この文章を変えて」

「このボタンを消して」

「新しいページを作って」

大切なこと

権限は、このホームページだけに限定するのがおすすめです

GitHubはホームページ本体を編集できる場所です。

必要以上に広いアクセス権を渡す必要はありません。対象ホームページのリポジトリだけを選び、必要な編集権限だけを許可する運用がおすすめです。

  • 対象のホームページだけを接続する
  • 関係のないリポジトリには権限を広げない
  • 接続先が分からない場合は、ホームページを制作した担当者へ確認する

CONNECTED = SIMPLE

接続後は、変更したいことを
チャットで伝えるだけ。

HTMLや管理画面を覚える必要はありません。変更したい内容を普段の言葉で伝えて、反映後のホームページを確認してください。
