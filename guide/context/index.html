重要：チャットが長くなったとき

重い・遅いと感じたら、
新しいチャットへ安全に引き継ぐ。

同じチャットを無理に使い続けなくて大丈夫です。大切なのは、今までの決定や作業状況を短くまとめてから、新しいチャットへ移ることです。

先にこれだけ覚えてください

「引き継ぎ用まとめを作って」→ 新しいチャット → まとめを貼って「ここから続けて」

チャットの長さ以外も確認

1. ページを再読み込み

一時的な表示不具合なら、これだけで直ることがあります。

2. アプリ・ブラウザを再起動

スマホやPCのChatGPTをいったん閉じて開き直します。

3. 別のブラウザ・回線を試す

VPNや拡張機能が影響している場合もあります。

4. 障害情報を確認

サービス側の混雑や障害なら、少し時間を置くのが安全です。
