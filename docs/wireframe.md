# ワイヤーフレーム — チャットホームページ LP

対象: 1ページ構成のサービスLP（GitHub Pages / 静的HTML）。
方針: モバイルファースト。主要コンテンツはHTMLのみで表示完了。JSは補助のみ。

## セクション構成（上から順）

1. **Header / Nav**
   - ロゴ（テキスト）「チャットホームページ」
   - ナビ（デスクトップ: インライン / モバイル: トグルメニュー、ただし主要リンクは`<details>`不要でCSSのみ開閉可能に）
   - ヘッダー右端に常時CTA「無料相談する」（`#contact`へのアンカー）

2. **Hero**
   - H1: 「ホームページは、話すだけ。」
   - サブコピー: 「制作はプロにおまかせ。公開後の変更も、チャットで伝えるだけ。」
   - CTA主ボタン「無料相談する」+ 補助リンク「仕組みを見る」（`#how-it-works`）
   - 画像なし。チャットUIをCSSで簡易再現したビジュアル（後述デモと同系統の軽量表現）

3. **Pains（悩み）**
   - 見出し「こんな悩み、ありませんか？」
   - 5項目リスト（アイコン装飾は最小限、絵文字またはCSS疑似要素）
     - 何から始めればいいか分からない
     - 公開後に更新できない
     - 制作会社への連絡が面倒
     - 管理画面を触りたくない
     - 写真・営業時間をすぐ変えたい

4. **Benefits（3つの価値）**
   - 見出し「チャットホームページが選ばれる理由」
   - 3カラム（モバイルは縦積み）: 制作はプロ / 更新はチャット / 技術知識ゼロ
   - 各項目に短い説明文（1-2文）

5. **Steps（3ステップ）**
   - 見出し「はじめかたは3ステップ」
   - 番号付きステップ: 希望を話す → こちらで制作 → 公開後はチャットで更新
   - 数字は大きなタイポで表現（装飾控えめ）

6. **Chat Demo（更新デモ）**
   - 見出し「公開後の更新は、こんな感じです」
   - チャット風のふきだしUI（HTML/CSSのみ、画像なし）
     - ユーザー発話: 「営業時間を18時までに変えて」
     - 応答: 反映済みの表示
     - ユーザー発話: 「この写真に差し替えて」
     - ユーザー発話: 「来週のキャンペーン載せて」
   - 締め: 「本当にこれだけ」を大きく強調表示

7. **Use Cases（活用シーン）**
   - 見出し「こんな事業者様に」
   - 6項目グリッド: 建築・工務店 / 店舗 / 美容 / 飲食 / 会社 / 個人事業

8. **Features（機能一覧）**
   - 見出し「できること」
   - リスト形式（カード乱発を避け、区切り線ベースのリスト or 2カラムグリッド）
     - レスポンシブ対応 / 独自ドメイン / お問い合わせフォーム / 基本的なSEO対応
     - 写真・営業時間・価格・お知らせの更新 / Googleマップ設置 / SNS連携 / 予約システム連携

9. **Comparison（比較表）**
   - 見出し「普通のホームページ制作との違い」
   - テーブル（モバイルは横スクロール可、または見出し付き縦積みに変換）
     - 行: 公開後の更新方法 / 更新にかかる時間 / 必要な知識 / 連絡方法 など
     - 列: 普通のホームページ / チャットホームページ

10. **Pricing（料金）**
    - 見出し「料金について」
    - 「個別見積もり」である旨を明記。初期制作費 + 月額チャット運用費の2段構成をテキストで説明
    - 具体的な金額は記載しない。CTAへ誘導（「まずは無料相談で内容を伺います」）

11. **Flow（ご利用の流れ）**
    - 見出し「ご利用の流れ」
    - 6ステップ: 無料相談 → ヒアリング → デザイン → 確認 → 公開 → チャット運用
    - 縦型タイムライン表現（CSSのみ）

12. **FAQ**
    - 見出し「よくある質問」
    - `<details>/<summary>`によるネイティブ開閉（JS不要でアクセシブル）
    - 質問: PCがなくても大丈夫か / サーバーは必要か / 独自ドメインは使えるか / WordPressか / 写真は用意する必要があるか / 更新回数に制限はあるか / 解約・引き渡しはできるか / 既存サイトからの移行は可能か

13. **Final CTA**
    - 見出し「ホームページの管理画面、もう覚えなくていい。」
    - サブ: 「変更したいことは、チャットしてください。」
    - CTAボタン「無料相談する」

14. **Contact（相談導線）**
    - `id="contact"`
    - 実際に送信可能なフォームは実装しない（送信先未確定のため）
    - 相談用の連絡先（メール等）を明記する枠を用意し、「制作開始前に正式な相談窓口を接続予定」である旨を明示
    - 誤解を招く「送信できるふりをするフォーム」は作らない

15. **Footer**
    - サービス名、コピーライト、簡易サイト内リンク（プライバシー等は今回スコープ外のため省略可）

## モバイル/デスクトップの差分方針
- 320〜430px: 1カラム縦積み、ナビはハンバーガー的トグル（CSSのみ or 最小JS）
- tablet(600px〜): 2カラムグリッドをbenefits/use-cases/featuresに適用
- desktop(1024px〜): 比較表は通常テーブル表示、heroは左テキスト+右チャットデモの2カラム
- large(1440px〜): 最大幅コンテナで余白を最大化、フォントサイズをやや拡大
