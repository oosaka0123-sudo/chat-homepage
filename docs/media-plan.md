# メディアプラン — チャットホームページ LP

## v1方針（今回の実装スコープ）

- v1では写真・イラスト・動画を一切使用しない。ヒーローを含む全セクションをタイポグラフィ・余白・CSSのみで構成する。
- 理由: AGENTS.mdの優先順位（表示速度 > ユーザビリティ > コンテンツ > レスポンシブ > デザイン > モーション > AI）に従い、初期表示経路に画像/動画の重量を持ち込まない。また、実在しない制作実績・顧客写真を使うと誇大表現になるため、確証のあるビジュアルが用意できるまでは画像を使わない。
- チャットデモは実際の写真ではなく、CSSで組んだふきだしUIで表現する（「この写真に差し替えて」という発話テキスト自体はサンプルコピーであり、実画像は伴わない）。

## 将来の画像・動画追加計画（v2以降）

### 追加候補箇所
1. Hero右カラム: 実際の管理画面/チャット画面のスクリーンショットまたは短尺ループ動画（自社サービス画面ができ次第）
2. Use Cases（6業種）: 各業種の代表的な完成サイトのスクリーンショット（実制作物ができ次第、許諾を得た上で掲載）
3. Steps（3ステップ）: プロセスを示す簡易図解（イラストまたはスクリーンショット）
4. Features: Googleマップ設置・予約連携などの実画面キャプチャ

### 制作方針
- 実際に制作したサイト/機能のスクリーンショットを優先。ストック素材やAI生成画像で「実績っぽく見せる」演出はしない（誤解を招く表現の禁止に抵触するため）。
- 人物写真を使う場合は実在のクライアント・許諾済み素材のみ。顔破綻や不自然な生成物は不可。
- 動画を使う場合は自動再生+ミュート+`playsinline`、`prefers-reduced-motion`時は静止画にフォールバック。

### フォーマット・パフォーマンス要件
- 画像: WebP（フォールバック不要、モダンブラウザ前提）、レスポンシブ`srcset`、`loading="lazy"`（ヒーロー直下以外）、`width`/`height`属性必須でCLS防止。
- ヒーロー画像を追加する場合のみ`fetchpriority="high"`+`loading="eager"`を検討し、LCP 2.5s以内を維持できるかを計測してから採用する。
- 動画: 5秒以内のループ、H.264/MP4、1MB以下を目安。自動再生は音声なしのみ。
- 各画像に具体的な代替テキスト（`alt`）を必ず設定する。装飾目的のみの画像は`alt=""`。

### 実施タイミング
- 実制作事例が1件以上でき次第、Use Casesセクションから順に画像を追加する。
- ヒーロービジュアルは自社の「チャット運用画面」が完成してから差し替える（現時点ではCSSデモで代替）。
- 画像追加時は必ずLighthouse計測を再実施し、LCP/CLSがAGENTS.mdの目標値を超えないことを確認する。
